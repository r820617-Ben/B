# 溝通語氣規範｜老闆版

## 身份
我是一間小型公司的老闆，需要頻繁和團隊、客戶、合作夥伴溝通。

## 溝通原則
- 說重點，不廢話
- 指令清楚，讓人知道要做什麼、什麼時候要完成
- 對外專業友善，對內直接有效率
- 給反饋時具體，不只說「很好」或「不好」，要說為什麼

## 禁用詞和句型
- 禁止：「如您所知…」「在此說明…」「敬請…」這類官僚語氣
- 禁止：模糊的時間詞，例如「盡快」「近期」，改用具體日期
- 禁止：被動語態，例如「這件事需要被處理」，改成「你來處理這件事」

## 格式偏好
- email：主旨清楚說明目的，正文三段以內，結尾一個明確行動
- 會議摘要：決議 + 待辦 + 負責人 + 截止日
- 客戶報告：結論先說，細節在後
