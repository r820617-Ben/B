# 迴圈：內容產製

## 目標
依企劃的策略主軸和執行方案，產出第一個月的內容，放在 `content/<客戶>-<日期>/`，
並寫一份 `內容總表.md` 當索引。

單獨跑（不在流水線裡）時，「本次輸入」放主題就好，不需要企劃。

## 輸入
- 「本次輸入」底下是這個客戶的行銷企劃全文，策略主軸和執行方案是這一關的依據
- 語氣：客戶的 `clients/<客戶>/CLAUDE.md`，沒有的話用 `.claude/skills/brand-voice.md`
- 禁用規則：`anti-style.md`

## 每輪要做的事
1. 從企劃的「執行方案」看第一個月要幾則、什麼形式
2. 短影音腳本：`script-w1.md`～`script-w4.md`，每支開場鉤子（前 3 秒）＋ 2–3 個重點 ＋ CTA
3. IG 輪播：`carousel-w1.md`～`carousel-w4.md`，每則 7–8 張，第一張是停滑鉤子
4. `內容總表.md`：一張表列出每個檔案的形式、主題、對應週次、字數
5. 每一則都要看得出是在講企劃裡那句策略主軸，扣不上的重寫

## 停止條件（全部符合才算做完）
- [ ] `content/<客戶>-<日期>/內容總表.md` 存在
- [ ] 總表列出的每個檔案都真的存在
- [ ] 每支短影音腳本 270–405 字（口播 60–90 秒，以每秒約 4.5 字估算）
- [ ] 每則輪播 7–8 張
- [ ] 則數對得上企劃「執行方案」寫的第一個月頻率
- [ ] 開場鉤子沒有「教你如何」開頭，沒有「你是否曾經」開頭
- [ ] 結尾是問句或直接行動呼籲，沒有昇華感總結句
- [ ] 每一則都扣得上企劃的策略主軸，總表要有一欄寫它怎麼扣上
- [ ] 沒有違反客戶禁忌（brief 的「客戶的禁忌」欄）
- [ ] 通過 `anti-style.md` 全部禁用詞和禁用句型檢查

## 不要做的事
- 不要為了湊字數加廢話
- 不要在腳本裡加「！」製造情緒
- 不要做企劃沒排的渠道
