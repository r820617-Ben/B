# 12｜LINE 官方帳號後台操作手冊（無代碼版，今天就能上線）

## 0. 先說清楚這份跟前面 11 份的關係

前面 11 份是**完整版**：AI 動態生成診斷、Lead Scoring、自動通知顧問。那一版需要工程師接 Webhook、n8n、資料庫，11 到 16 個工作天。

這一份是**無代碼版**：只用 LINE 官方帳號後台既有功能，不寫一行程式，一個下午可以做完。診斷結果是預先寫好的 15 種，不是 AI 即時生成。

兩者不衝突。無代碼版先上線收真實反應，累積 50 到 100 筆之後，再用真實資料去校準完整版的題目和文案。先做這一版，完整版的成功率會高很多。

**這一版能做到的：** 六選一分流、兩層問答、15 種個人化診斷結果、聊天標籤分類、問卷收名單、圖文選單常駐入口。

**這一版做不到的：** AI Ready Score 分數、根據答案組合動態生成的分析、自動 Lead Scoring、自動通知 Slack、Day 1/3/7 自動追蹤。

## 1. 開始前的準備

登入 https://manager.line.biz/ 選擇知育行銷的帳號。

需要先確認的三件事：

| 項目 | 位置 | 要確認什麼 |
|---|---|---|
| 方案 | 主頁右上 帳號名稱 → 使用方案 | 輕用量方案每月 200 則免費訊息。這一版主要用「回應訊息」不計入額度，但群發會計入 |
| 權限 | 設定 → 權限管理 | 你必須是「管理員」才能改回應設定 |
| 現有設定 | 主頁 → 自動回應訊息 | 先截圖存檔，這次會覆蓋掉舊的 |

**動工前先把現有的自動回應訊息全部截圖。** 改壞了要能還原。

## 2. 第一階段｜基礎設定（約 15 分鐘）

### 2.1 回應設定

路徑：**主頁 → 設定 → 回應設定**

| 項目 | 設定成 | 理由 |
|---|---|---|
| 聊天 | 開啟 | 顧問要能接手 |
| 回應方式 | 自動回應訊息 開啟 | 診斷靠這個跑 |
| AI 自動回應訊息 | 關閉 | 會跟關鍵字回應打架，回出奇怪的內容 |
| 加入好友的歡迎訊息 | 開啟 | 下一步要改內容 |
| 回應時間 | 不設定（24 小時） | 診斷要隨時能跑 |

### 2.2 基本檔案

路徑：**主頁 → 設定 → 檔案**

| 欄位 | 填入 |
|---|---|
| 狀態消息 | 60 秒企業診斷｜AI 導入與數位成長顧問 |
| 簡介 | 知育行銷有限公司。協助企業把 AI 用進實際營運，不只是學會工具。<br>加入好友可免費做一次企業診斷，60 秒得到改善方向。 |
| 按鈕 | 顯示「開始診斷」，連結指向官網服務頁 |

狀態消息會出現在使用者的好友列表，是加好友之後第二眼看到的東西。寫服務項目沒用，寫他能得到什麼。

### 2.3 聊天標籤

路徑：**聊天 → 右側標籤管理**（或在任一聊天室右側新增）

先建這 14 個標籤，之後手動貼：

```
需求_行銷    需求_AI      需求_流程    需求_培訓    需求_策略
AI程度_低    AI程度_中    AI程度_高
熱_立即      溫_三個月    冷_觀望
已完成診斷   已留資料     已聯繫
```

無代碼版沒有自動打標籤功能，顧問看完對話後手動貼。一天不會超過 10 個人，成本可接受。

## 3. 第二階段｜圖文選單（約 20 分鐘）

路徑：**主頁 → 圖文選單 → 建立**

### 3.1 設定

| 項目 | 值 |
|---|---|
| 標題 | 知育企業診斷 主選單 |
| 使用期間 | 即日起，結束日期填三年後 |
| 選單列顯示文字 | 開始企業診斷 |
| 預設顯示方式 | 顯示 |
| 版型 | 大型 · 六格（2 列 3 欄） |

### 3.2 六格內容與動作

每一格的動作類型都選 **「文字」**，讓使用者點擊後等同於傳送那段文字，觸發關鍵字回應。

| 格子 | 圖上文字 | 動作類型 | 傳送文字 |
|---|---|---|---|
| 左上 | 行銷成效不穩 | 文字 | `#行銷` |
| 中上 | 想導入 AI | 文字 | `#AI` |
| 右上 | 重複工作太多 | 文字 | `#流程` |
| 左下 | 想提升團隊 | 文字 | `#培訓` |
| 中下 | 經營策略卡住 | 文字 | `#策略` |
| 右下 | 不確定問題 | 文字 | `#不確定` |

### 3.3 圖片規格

| 項目 | 值 |
|---|---|
| 尺寸 | 2500 × 1686 px |
| 格式 | PNG 或 JPG |
| 檔案大小 | 1 MB 以內 |
| 單格可視範圍 | 833 × 843 px |

**視覺建議**：深色底（接近 `#0E1116`）、金色線條與文字（`#C8A96A`）、每格一個細線圖示加一行字。不要用滿版照片，手機上看會糊。這組配色跟完整版的 Flex 卡片一致，之後升級不用重做。

用 Canva 做的話，建立 2500 × 1686 的自訂尺寸，拉三欄兩列的參考線，每格置中。

## 4. 第三階段｜加入好友的歡迎訊息（約 10 分鐘）

路徑：**主頁 → 加入好友的歡迎訊息**

設兩則訊息（同一個編輯畫面可以加第二則）。

```
嗨，我是知育 AI 成長助手。

你從官網走到這裡，我就直接做給你看，不多做介紹。

接下來大約 60 秒，我會問你兩個問題，幫你找出三件事：

① 目前最值得優先改善的地方
② 哪些工作適合先導入 AI
③ 知育可以從哪裡開始協助你
```

### 訊息 2

```
你的回答只會用在這份診斷和後續聯繫，隨時可以停。

先從第一題。你現在最有感的是哪一件？

請點下方選單，或直接回覆代碼：

#行銷　行銷成效不穩定
#AI　　想導入 AI 但沒方向
#流程　團隊重複工作太多
#培訓　想提升團隊能力
#策略　品牌經營策略卡住
#不確定　還不確定問題在哪
```

## 5. 第四階段｜自動回應訊息（約 90 分鐘）

路徑：**主頁 → 自動回應訊息 → 建立**

每一則都這樣設：
- 標題：用下表的編號，方便之後找
- 關鍵字：用下表的關鍵字，比對方式選 **完全一致**
- 生效期間：不設定
- 星期與時間：不設定

一共要建 **27 則**。照順序做，不要跳。


### 5.5 流程線結果（3 則）

#### `R-P1`｜關鍵字 `P1`

```
【你的企業診斷結果】

目前狀態
資料整理和報表吃掉大量時間。這一類工作的特徵是重複、有明確規則、而且做完不會增加價值。

最可能的原因
資料散在不同地方，每次都要重新彙整。真正貴的不是時間，是它讓人沒有餘裕思考。

先做這三件事
① 記錄一週，算出實際花掉多少小時。多數老闆估的數字低於實際的一半
② 確認資料的原始來源有幾個
③ 把報表要回答的問題寫下來，通常不超過五個

這一類最適合自動化
固定格式的報表，是自動化投資報酬率最高的起點。做對的話，每週省下的時間可以直接換算成金額。

想聊得更細，回覆「顧問」，我幫你排。
```

#### `R-P2`｜關鍵字 `P2`

```
【你的企業診斷結果】

目前狀態
客服和訊息回覆佔掉太多時間，而且無法排程，會打斷其他工作。

最可能的原因
八成的問題集中在兩成的題目上，但因為沒有整理過，每次都當新問題處理。

先做這三件事
① 把過去一個月的詢問抓出來，分成五到八類
② 每一類寫一段標準回覆
③ 標出哪幾類可以完全自動回，哪幾類一定要真人

這一類最適合自動化
常見問題分流加上自動回覆，通常可以吃掉五成到七成的量，剩下的留給真人處理。

想聊得更細，回覆「顧問」，我幫你排。
```

#### `R-P3`｜關鍵字 `P3`

```
【你的企業診斷結果】

目前狀態
內容產出佔掉大量時間，而且產出量跟品質很難同時維持。

最可能的原因
每次都從零開始。沒有素材庫、沒有固定結構、沒有可重複的流程，所以每一篇都像第一篇。

先做這三件事
① 把過去表現最好的五篇內容找出來，拆解它們的結構
② 把結構寫成模板
③ 建立一份素材庫，放品牌資訊、常用說法、案例數字

這一類最適合導入 AI
有了模板和素材庫，AI 產出初稿的品質會跳一個層級。沒有這兩樣東西，AI 寫出來的就是通用內容。

想聊得更細，回覆「顧問」，我幫你排。
```

### 5.6 培訓線結果（3 則）

#### `R-T1`｜關鍵字 `T1`

```
【你的企業診斷結果】

訓練對象
主管層。這一層的訓練重點跟執行層完全不同。

最常見的誤區
主管訓練如果只教工具操作，上完課不會有改變。主管要的是判斷力：哪些工作值得導入、怎麼評估成效、怎麼帶團隊一起改。

建議的課程結構
① 判斷哪些工作適合 AI 化的思考框架
② 用自己部門的真實工作當案例實作
③ 導入後的衡量方式與管理節奏

適合的形式
工作坊型態，半天到一天，一定要帶自己部門的真實案例來。純聽講的主管課，三個月後使用率接近零。

想聊得更細，回覆「顧問」，我幫你排。
```

#### `R-T2`｜關鍵字 `T2`


## 10. 什麼時候該升級到完整版

出現以下任一情況，就值得投入 11 到 16 天做完整版：

| 訊號 | 代表什麼 |
|---|---|
| 每月完成診斷超過 50 人 | 手動貼標籤和判斷分級開始吃掉太多時間 |
| 固定的 15 種結果開始重複遇到同一個人 | 使用者會發現這是罐頭，體驗價值下降 |
| 有人問「可以再細一點嗎」 | 使用者要的是 AI 動態分析，不是預設答案 |
| 顧問開始漏接名單 | 需要自動通知與 SLA 追蹤 |
| 想在官網也放同一套診斷 | 需要可重複使用的後端 |

在那之前，先用這一版收 50 到 100 筆真實回答。這些資料會告訴你：哪一題流失最多、哪個 Segment 的人最多、哪一種結果最多人回「顧問」。完整版的題目和文案照著這些資料改，成功率會高很多。
