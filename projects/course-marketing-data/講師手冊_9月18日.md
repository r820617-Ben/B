## 三、練習 3 分組資料（印給學員，解答保留）

> 共同條件：同一電商客戶、同一週、客單價 NT$980、毛利率 45%（**CPA 上限 NT$265、損益兩平 ROAS 2.2**）

### 第一組｜甲帳戶

| 指標 | 數值 |
|---|---|
| 花費 | NT$18,000 |
| CPM | NT$210 |
| CTR | 3.1% |
| 頻率 | 2.0 |
| CVR | 0.4% |
| 購買數 | 11 |
| CPA | NT$1,636 |
| ROAS | 0.7 |

**解答**：斷點在到站／轉換層。CTR 3.1% 證明素材與受眾都對，問題在落地頁。第一個動作是用手機檢查第一屏訊息一致性與載入速度，不要動廣告。預期 CVR 從 0.4% 拉到 1.2% 以上，CPA 降到 600 以內。

### 第二組｜乙帳戶

| 指標 | 數值 |
|---|---|
| 花費 | NT$22,000 |
| CPM | NT$186 |
| CTR | 0.7% |
| 頻率 | 1.6 |
| CVR | 2.4% |
| 購買數 | 20 |
| CPA | NT$1,100 |
| ROAS | 1.1 |

**解答**：斷點在互動層。CVR 2.4% 很健康，問題是進來的人太少。同受眾換三組新訴求素材測試，一次只改素材。預期 CTR 拉到 1.8% 以上，購買數翻倍，CPA 降到 500 附近。

### 第三組｜丙帳戶

| 指標 | 數值 |
|---|---|
| 花費 | NT$26,000 |
| CPM | NT$358 |
| CTR | 1.9% |
| 頻率 | 5.2 |
| CVR | 1.7% |
| 購買數 | 23 |
| CPA | NT$1,130 |
| ROAS | 1.3 |

**解答**：斷點在曝光層。頻率 5.2 加上 CPM 358，是典型的受眾打爛加素材疲乏。動作是擴大受眾並排除近 30 天已購買者，同時換素材。預期 CPM 回到 250 以下、頻率降到 3 以內。

> **共同追問**：三組都沒有達到 ROAS 2.2。如果只能保留一組繼續投，選哪一組？
> 引導方向：選乙。CVR 已經證明頁面與商品會賣，素材是最好修的變因；甲要等頁面改版、丙要等新素材產出，時間成本都比較高。

## 四、現場常見狀況

| 狀況 | 處理方式 |
|---|---|
| 學員沒有廣告後台權限 | 練習改用第三節的分組資料，並請他寫下回去要跟誰要權限 |
| 有人問到很細的技術設定（GTM、API） | 記在白板的「會後回答區」，不要當場展開，會吃掉進度 |

| 進度超前 | 加碼帶學員現場算自己的 LTV 與回收期（延伸 P15） |
