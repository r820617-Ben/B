# 人生遊戲計畫|六元素

重置日隔天填。把前三份檔案的洞見收斂成一頁,這一頁之後就是你和 Claude 排任務、做內容、接案子的判斷標準。

| 遊戲元素 | 對應 | 你的答案 |
|----------|------|----------|
| 賭注 | **反願景**:我再也不想經歷的人生是什麼? | |
| 勝利條件 | **願景**:我想要、且會邊走邊修的理想人生? | |
| 主線任務 | **一年目標**:一年後我的人生長什麼樣?有更接近願景嗎? | |
| 魔王戰 | **一個月專案**:要學什麼、建什麼,才能更接近一年目標? | |
| 每日任務 | **每日行動**:哪些是真正推動專案的優先任務? | |
| 遊戲規則 | **限制條件**:我不願意犧牲什麼? | |

---

## 填完之後的固定節奏

- **每天**:每日行動排進早上深度工作時段(沒會議就是行動時間)
- **每週**:叫 Claude 對照這一頁檢查——本週做的事有推進一個月專案嗎?自己的內容和客戶代理的時間分配,有符合一年目標嗎?
- **每月**:魔王戰打完換下一場。更新「一個月專案」那格,舊的留著存檔
- **每年**:整套重置流程重跑一次

## 為什麼有用

這六個元素會形成同心圓力場,擋掉干擾和亮晶晶的新東西。玩越久力量越強,最後它會變成你是誰。
