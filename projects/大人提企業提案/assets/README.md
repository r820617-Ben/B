# 品牌資產

## 放入 LOGO 的方式

從 Drive「知育行銷」資料夾把以下兩個檔案放進本目錄，然後重跑 `node build_deck.js`，
簡報會自動把 LOGO 放上封面、章節頁、封底與各內頁右上角：

| 檔名（必須一致） | 用途 | Drive 來源 |
|---|---|---|
| `知育LOGO.png` | 淺色底頁面 | 知育行銷／知育LOGO.png |
| `白色LOGO.png` | 深藍底頁面（封面、章節頁、封底） | 知育行銷／白色LOGO.png |

檔案不存在時，簡報會自動改用文字標準字（知育行銷 ZHIYU MARKETING），版面不會破。

## 品牌色

| 用途 | 色碼 | 來源 |
|---|---|---|
| 品牌主色 | `#284EA0` | 取自 知育LOGO.png 的實色填充 |
| 深藍底 | `#14264D` | 主色延伸的深色版 |
| 輔助金 | `#C9A227` | 深藍底上的強調色 |
