# 大人提企業提案簡報

115 年度企業人力資源提升計畫（大人提）對外提案簡報，主軸為**服務範疇**與**計劃執行**。
階段設定：初次接觸／比稿（不放死價，只給級距）。

## 檔案

| 檔案 | 說明 |
|---|---|
| `build_deck.js` | 簡報產生器（pptxgenjs） |
| `知育行銷_大人提_服務範疇與計劃執行提案.pptx` | 產出檔，21 頁，含每頁講稿備忘 |

## 重建方式

```bash
npm install pptxgenjs      # 或連結既有的 node_modules
node build_deck.js
```

## 資料來源與待確認事項

計畫規則（補助上限、資格、補助比率、9/30 截止）取自勞動力發展署公開資訊。
以下三項為推定值，正式對外前需確認：

1. **第 15 頁服務承諾的天數**——目前為建議值（3／5／14／3／5／15 個工作天），需確認團隊實際負荷。
2. **第 18 頁客戶名單**——需確認哪些客戶同意具名於對外簡報。
3. **第 20 頁聯絡資訊**——電話沿用舊版底稿，Email 改為 zhiyumkt@gmail.com。
