# 大人提企業提案簡報

115 年度企業人力資源提升計畫（大人提）對外說明簡報。

**設計原則：頁面只放企業閱讀用的說明資料，說服邏輯全部寫在講稿備忘（speaker notes）。**
簡報可以留給對方帶回去看，現場的說法由執行長自己講。

## 檔案

| 檔案 | 說明 |
|---|---|
| `build_deck.js` | 簡報產生器（pptxgenjs） |
| `知育行銷_大人提_計劃說明與服務內容.pptx` | 產出檔，25 頁，每頁附講稿備忘 |

## 重建方式

```bash
npm install pptxgenjs
node build_deck.js
```

### LOGO 置入

`build_deck.js` 會自動偵測 `assets/` 內的 LOGO 檔並置入封面、章節頁、封底與各內頁右上角。
**目前 assets/ 內沒有 LOGO 檔，簡報使用文字標準字（知育行銷 ZHIYU MARKETING）。**
放入檔案後重跑 `node build_deck.js` 即會換成圖檔，版面不需調整。放法見 `assets/README.md`。

## 資料來源

計畫規則（三種類型補助上限、51 人資格門檻與四條替代條件、50%／70% 補助比率、
115 年度受理至 9/30）取自勞動力發展署公開資訊。

課程分類、課程大類清單、人數與時數規格、必填欄位，取自
Drive 的 `信功肉品_大人提計畫480小時_匯入課程範本V5.xlsx`（政府端匯入範本）。

信功肉品案例的 24 門課程、480 小時、課程名稱與時數，同樣取自該範本檔，
其中 12 門 16 小時 + 12 門 24 小時 = 480 小時。
第 22 頁的能力面向時數分布為依課程性質重新歸類後的計算結果：
影音 128、管理職能 128、社群廣告 112、數據 AI 56、內訓平台 56。

## 對外前需確認

1. **第 14 頁作業時程**——3／5／14／3／5／15 個工作天為建議值，需確認團隊實際負荷。
2. **第 21、23 頁企業名稱**——需確認哪些客戶同意具名於對外簡報。
3. **第 18 頁著作權條款**——課程成果影音的權利歸屬與作品集展示權寫法需確認。
4. **第 24 頁聯絡資訊**——電話沿用舊版底稿，Email 為 zhiyumkt@gmail.com。
